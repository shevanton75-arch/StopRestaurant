Endpoint para recibir nuevos usuarios
Configura tu sistema externo para enviar un POST a esta URL con los datos del usuario. El sistema creará la cuenta automáticamente en Firebase Auth y Firestore.
Esta función requiere Firebase Cloud Functions (plan Blaze). Mientras tanto, puedes usar el registro manual desde la pantalla de Usuarios.
Formato del payload JSON esperado
El sistema externo debe enviar un POST con el siguiente cuerpo:
{ "email": "nuevo@restaurante.com", "password": "contraseña_segura", "name": "Nombre Completo", "role": "staff", // "admin" o "staff" "secret": "TU_SECRET_KEY" // clave de seguridad configurada }
